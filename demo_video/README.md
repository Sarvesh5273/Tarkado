# Tarkado illustrative demos

These are browser-playable, silent compositions, not recordings of private company
work or proof of deployed routing. All people, interfaces, tasks and values are fictional.

- [`current-implementation/player.html`](current-implementation/player.html):
  implemented-mechanics walkthrough with explicit controlled/pending labels.
- [`videos/tarkado-deployment-workflow/presentation.html`](videos/tarkado-deployment-workflow/presentation.html):
  concept simulation of the intended company deployment journey.

Read each project's README for playback controls and its recorded validation. GitHub's
file viewer displays HTML source, not an automatically hosted running application.
No GitHub Pages deployment, render or runtime upgrade is performed by publication.
No demo changes the actual Tarkado service, permissions, private stores or pilots.

Composition source, browser wrappers, reviewed screenshots, briefs and required local
assets are included. Raw authoring captures and local `.media` / `.hyperframes` state
remain on disk but are excluded from Git. Third-party notices are in
[`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md). They do not select a licence for
Tarkado's own code or demonstrations.
